☁️ Hamisha data ya BandoManager

Nakili data za BandoManager pekee kutoka Firebase ya zamani kwenda project mpya. Data nyingine za SmartBundles haziguswi. Backup ya JSON itapakuliwa kwanza; data ya chanzo haitafutwa.

Kabla ya kuanza, simamisha mauzo na funga mfumo kwenye vifaa vingine hadi uhamisho ukamilike.

💾 Backup ya Data

Pakua data yako yote — laini, mauzo, mabando, wateja, mikopo, na orders — kwa faili moja. Hifadhi mahali salama (Google Drive, email, n.k).

⚠️ Rudisha Data (Restore)

Hii itabadilisha data yote ya sasa na ile iliyomo kwenye faili la backup. Tumia tu kama una uhakika.
